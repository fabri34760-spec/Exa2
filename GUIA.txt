Cada receta sigue los mismos pasos: archivo, qué buscar, qué pegar, dónde queda, import, cómo personalizarlo y cómo se verá.

  - Los números de línea son los del archivo original. Si ya pegaste otra receta, los números se mueven, pero el texto de "BUSCA CON CTRL+F" sigue sirviendo.
  - "DÓNDE QUEDA" es solo para ver la posición. Copia siempre desde "PEGA ESTE CÓDIGO". Las marcas // <<< NUEVO no se copian: dentro del JSX romperían la pantalla.
  - Si dos recetas agregan algo al mismo import, deja todos los nombres dentro de las mismas llaves, separados por coma. Ej: import { Buscador, CampoTexto, ItemUsuario, TarjetaProducto } from '@/componentes/moleculas';
  - Si usas dos recetas con useState, cada estado necesita un nombre distinto (ya vienen con nombres distintos).
  - Después de pegar: guarda con Ctrl+S y, si el celular no cambia, presiona r en la terminal.

9. CREAR UN COMPONENTE NUEVO
==============================================================================

Ejemplo completo: un átomo Precio (texto grande verde).

--- PASO 1. COPIAR UN ARCHIVO PARECIDO ---

Copia src/componentes/atomos/Etiqueta.tsx y llama a la copia Precio.tsx (misma carpeta).

--- PASO 2. RENOMBRAR Y ESCRIBIR EL COMPONENTE ---

Reemplaza todo el contenido de Precio.tsx por esto:

  >>> CODIGO >>>
    /**
     * QUÉ ES: Precio grande en color.
     * Colores en estilos.ts -> PRECIO.
     *
     * PROPS:
     *   valor -> el precio a mostrar (ej. "$199")
     *
     * EJEMPLO DE USO:
     *   <Precio valor="$199" />
     */
    import { precio } from '@/estilos/estilos';
    import { Texto } from './Texto';
    
    type PrecioProps = {
      valor: string;
    };
    
    export function Precio({ valor }: PrecioProps) {
      return (
        <Texto color={precio.color} tamano={precio.tamano} negrita>
          {valor}
        </Texto>
      );
    }
  <<< FIN CODIGO <<<

--- PASO 3. AGREGAR SU BLOQUE DE ESTILOS ---

Al final de src/estilos/estilos.ts pega esto, y agrega "PRECIO" al índice de arriba:

  >>> CODIGO >>>
    // ==================== PRECIO ====================
    export const precio = {
      color: '#16A34A', // verde
      tamano: 20,
    };
  <<< FIN CODIGO <<<

--- PASO 4. EXPORTARLO EN EL INDEX.TS DE SU CARPETA ---

En src/componentes/atomos/index.ts agrega:

  >>> CODIGO >>>
    export * from './Precio';
  <<< FIN CODIGO <<<

--- PASO 5. IMPORTARLO EN INDEX.TSX ---

Agrégalo al import de átomos (línea 10):

  >>> CODIGO >>>
    import { Boton, Espacio, Etiqueta, FotoPerfil, Precio, Texto } from '@/componentes/atomos';
  <<< FIN CODIGO <<<

--- PASO 6. USARLO ---

  >>> CODIGO >>>
    <Precio valor="$199" />
  <<< FIN CODIGO <<<

Para una molécula u organismo es igual, pero en su carpeta (moleculas/ u organismos/), importando átomos desde '@/componentes/atomos' y exportándolo en el index.ts de esa carpeta.

11. PROBLEMAS COMUNES
==============================================================================

--- NO SE VE EL CAMBIO EN EL CELULAR ---

  - Guarda el archivo (Ctrl+S).
  - Presiona r en la terminal donde corre Expo, o agita el celular y toca Reload.
  - Si corres Expo desde WSL sobre /mnt/c, no se recarga solo: siempre presiona r.
  - Si sigue igual, detén el servidor (Ctrl+C) y vuelve a levantarlo con --clear.

--- PANTALLA ROJA DE ERROR ---

  - Lee la primera línea del error: dice el archivo y la línea.
  - Import mal escrito: revisa la ruta ('@/componentes/atomos', no 'atomo') y que el componente esté dentro de las llaves del import.
  - Etiqueta sin cerrar: cada <Algo> necesita </Algo>, o terminar en />.
  - Texto fuera de <Texto>: error "Text strings must be rendered within a <Text> component". Todo texto visible va dentro de <Texto>...</Texto>.
  - Comentario en la misma línea que un elemento: {/* ... */} después de un elemento puede dejar un espacio suelto; pon el comentario en la línea de arriba.
  - Icono que no existe: el nombre tiene que estar en la lista ICONOS de Icono.tsx.
  - Coma o llave de más/menos en ejemplo.ts o estilos.ts: cada objeto termina en "},".

Para encontrar errores sin abrir el celular:

  >>> CODIGO >>>
    npx tsc --noEmit
  <<< FIN CODIGO <<<

--- LEVANTAR EL SERVIDOR ---

En PowerShell, dentro de C:\Users\Fabricio\Videos\Exa:

  >>> CODIGO >>>
    npx expo start --tunnel --clear
  <<< FIN CODIGO <<<

Si pregunta por instalar @expo/ngrok, responde Y (lo necesita el modo túnel). Si el celular está en la misma red wifi, también sirve sin túnel:

  >>> CODIGO >>>
